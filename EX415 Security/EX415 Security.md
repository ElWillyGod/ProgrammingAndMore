# RED HAT CERTIFIED SPECIALIST IN SECURITY: LINUX EX415

Duración: 4hs

Puntos para pasar: 210/300

> [!tip] 💡 Tips
> Usualmente los pedidos vienen entreverados, te plantean el escenario deseado y quizas para obtenerlo tengas que hacer bastantes pasos.

# Preguntas examen

1. Encriptar disco (lv) con LUKS y cargar contenido dentro de este.
2. Configurar nodo como nbde server, configurar nodo como cliente y configurar nueva particion para auto montaje
3. Montar USB, crear filesystem y copiar contenido en este. Bloquear, restringir otros USBs y generar politica por defecto para bloqueo de nuevos USBs
4. Configurar AIDE para monitoreo de directorio.
5. Configurar reglas de auditoria para modificación de directorios
6. Configurar reglas de auditoria para registrar cambios por usuario/grupo
7. Configurar perfil indicado con PAM y configurar minimos requisitos de pwquality
8. Configurar control ansible node para el uso del usuario admin y ejecucion de playbook desde shell
9. Configurar Automation Platform para que el usuario samuel pueda crear templates, inventarios y hosts. Permitiendole tambien el uso de la credential SSH existente.
10. Habilitar SELinux en VM
11. Configuracion SELinux login/user
    1. Se debe poder configurar que ciertos roles con SELinux Permissive permita sin contraseña ejecucion de sudo o su pero en Enforcing no
    2. Se debe configurar que ciertos roles con SELinux en ambos modos permita el sudo o su sin contraseña
12. Configuracion de SCAP en nodo 5, realizar escaneo
13. Generar reporte a base de escaneo realizado
14. Generar escaneo custom y ejecutarlo en nodo 5 (En Control Node por consola se tiene SCAP Workbench)
15. Generar fix sobre resultado de examen custom
