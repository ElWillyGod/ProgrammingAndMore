# Preguntas examen

- Crear ORG y Locations, asignar correspondientemente cada ORG a las ubicaciones necesarias.
- Crear CV, LifeCycle, AK con los repositorios indicados y nombres solicitados.
- Crear Producto Custom. Dejar disponible este en CV para clientes.
- Subscribir clientes a Satellite
- Actualizar a ultimo punto clientes subscriptos e instalar paquete custom.
- Gestion de usuarios (Crear y asignar roles).
- Distribucion de Keys SSH default de Foreman para uso de Ansible.
- Importacion de Roles Ansible a Satellite.
- Aplicaciones de roles Ansible directo sobre clientes.
- Instalar Capsula.
- Crear SubNet y Dominio.
- Preparar ambiente para onboarding para KickStart.
- Aprovisionamiento de VM desde Satellite.
- Respaldo OnLine de Satellite.
